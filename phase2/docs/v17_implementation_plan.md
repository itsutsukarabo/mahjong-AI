# v17 実験計画: 自己回帰デコード

## 動機

v16 の牌間 attention は「表現の整合性」を改善するが、予測ヘッドは依然として 34 牌を**独立に**出力する。自己回帰デコードでは、牌 i の予測が「牌 0〜i-1 の予測結果」に条件付けられるため、**手牌構造（面子・対子・浮き牌）をモデルが内部的に発見**できる。

## アーキテクチャ変更

**v16 ヘッド（並列）:**
```
Transformer出力 (B,3,34,d) → 牌間Attn → Linear → (B,3,34,5)
```

**v17 ヘッド（自己回帰）:**
```
Transformer出力 (B,3,34,d) → Causal Transformer Decoder (34ステップ) → (B,3,34,5)
```

予測ヘッドを小さな **Causal Transformer**（因果マスク付き、2層程度）に置き換える。

```python
# 学習時: 教師強制 (teacher forcing)
# 入力トークン: [BOS, c_0, c_1, ..., c_32]  (シフト済みラベル)
# 出力:         [c_0,  c_1, c_2, ..., c_33]  (各位置でクラス分類)

decoder_input = torch.cat([bos, count_embed(labels[:,:,:-1])], dim=-2)  # (B,3,34,d)
out = causal_decoder(decoder_input, memory=transformer_out)              # (B,3,34,d)
logits = head(out)                                                        # (B,3,34,5)
```

**推論時**: ステップごとに前の予測を使って次を生成（34ステップ逐次）。

## 主な設計上の判断点

| 項目 | 選択肢 | 方針 |
|------|--------|------|
| 牌の並び順 | 固定(0-33) / 残り枚数降順 | 固定で始める |
| 推論コスト | 34回 forward vs 1回 | 34ステップだが軽量ヘッドで許容範囲 |
| 合計制約 | DP デコードと併用 | 自己回帰でも sum≠k になりうるため DP は維持 |
| teacher forcing | 学習のみ / 推論は greedy | 標準的なアプローチ |

## 期待される効果

- 「字牌を2枚割り当てた後、残りの字牌に1枚を割り当てにくくなる」などの連鎖制約が自動学習される
- `hand_exact_acc`（手牌完全一致率）が大きく改善する可能性がある（v15: 20.7%）
- 推論は 34 ステップ逐次になるが、ヘッドは軽量なので 1 エポックの学習時間への影響は小さい
